# Javascript Examples
This repository contains Javascript examples with each example covering a javascript concept.

## How to use this repository?
You must clone the respository and open it using Visual Studio Code. The Visual Studio Code must have no Javascript extensions as the purpose is learning.

## Day-wise Topics Covered
### Day-01
1. History of Javascript
2. Relation between Javascript and Node.js
3. How to setup Node.js and Visual Studio Code.
4. var, let, const
5. Scope
6. Hoisting
7. Temporal Dead Zone
8. Primitive vs Reference types
9. null vs undefined
10. Pass by value vs reference

### Day-02
1. Type coercion
2. == vs ===
3. Truthy and falsy values
4. Functions
  1. Function declaration vs expression
  2. Arrow functions
  3. Callback functions
  4. Higher-order functions
